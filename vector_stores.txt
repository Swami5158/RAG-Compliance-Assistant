CHALLENGES :

1. Generating embedding vectors for huge data
2. Storing them and be able to access them in low cost multiple times
3. Semantic Search on vectors stored (costly search)

------------->> VECTOR STORE HELPS US SOLVE THESE CHALLENGES

it is system designed to store and retrieve data represented as vectors

Features :

1. Storage : can store metadata of vector with it , and give two storage options
            -> in memory (RAM) & on disk

2. Similarity Search : helps retrieve the most similar vector to given query vector

3. Indexing : it provides a DS or method that enables fast lookups

4. CRUD Ops
